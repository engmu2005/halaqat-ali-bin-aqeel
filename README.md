# تحضير درس بلوغ المرام – حلقات علي بن عقيل

سجل تحضير طلاب حلقات علي بن عقيل – درس بلوغ المرام – جمعية الدعوة.

تطبيق ويب خفيف يعمل مباشرة من GitHub Pages بدون أي خادم أو قاعدة بيانات. البيانات تُحفظ في متصفح الجهاز نفسه، ويمكن تثبيته على الجوال كتطبيق ويعمل بدون إنترنت.

**رابط الموقع:** https://engmu2005.github.io/halaqat-ali-bin-aqeel/

## المميزات

- **التحضير اليومي**: اختيار التاريخ (ميلادي + هجري)، وتسجيل حالة كل طالب بضغطة واحدة: حاضر / متأخر / غائب / مستأذن، مع ملاحظة اختيارية لكل طالب في اليوم.
- **تحضير الجميع كحاضر** ثم تعديل الاستثناءات فقط.
- **مشاركة ملخص اليوم عبر واتساب** أو نسخه (أعداد الحضور وأسماء الغائبين والمتأخرين).
- **إدارة الطلاب والحلقات**: إضافة فردية، إضافة قائمة أسماء دفعة واحدة، استيراد من Excel/CSV، أرشفة الطالب بدون حذف سجله.
- **التقارير**: نسبة حضور كل طالب، إحصائيات الجلسات، تنبيهات الغياب المتتالي مع زر تواصل واتساب، فرز الجدول بأي عمود.
- **تصدير Excel** (ملخص الطلاب + السجل اليومي + الجلسات) أو CSV، و**طباعة** بتنسيق مناسب.
- **نسخة احتياطية** كاملة بملف JSON واستعادتها على أي جهاز.
- **تطبيق قابل للتثبيت (PWA)** ويعمل بدون إنترنت بعد أول فتح.

## طريقة النشر على GitHub Pages

الموقع ملفات ثابتة فقط (`index.html` + CSS + JS)، فلا يحتاج أي بناء.

1. ادمج هذا الفرع في `main`.
2. من صفحة المستودع: **Settings → Pages**.
3. في **Build and deployment** اختر **Source: Deploy from a branch**، ثم **Branch: main** والمجلد **/ (root)**، واضغط **Save**.
4. بعد دقيقة تقريباً يصبح الموقع متاحاً على: `https://engmu2005.github.io/halaqat-ali-bin-aqeel/`

## ربط دومين خاص (لاحقاً)

بعد شراء الدومين (مثلاً `bulugh.app`):

1. في **Settings → Pages → Custom domain** اكتب الدومين واضغط **Save** (سيُنشئ GitHub ملف `CNAME` تلقائياً).
2. من لوحة تحكم مزوّد الدومين أضف سجلات DNS:
   - للدومين الرئيسي (`bulugh.app`) سجلات **A** إلى:
     `185.199.108.153` و `185.199.109.153` و `185.199.110.153` و `185.199.111.153`
   - للنطاق الفرعي `www` سجل **CNAME** إلى: `engmu2005.github.io`
3. انتظر حتى يتحقق GitHub من الدومين ثم فعّل **Enforce HTTPS**.

## أين تُحفظ البيانات؟

في `localStorage` داخل المتصفح على الجهاز نفسه (لا تُرسل إلى أي خادم). لذلك:

- استخدم **الإعدادات → تنزيل نسخة احتياطية** بانتظام.
- لنقل البيانات إلى جهاز آخر: نزّل نسخة احتياطية ثم **استعادة نسخة** على الجهاز الجديد.
- مسح بيانات المتصفح يحذف السجل، فاحرص على النسخ الاحتياطي.

## بنية المشروع

```
index.html                 واجهة التطبيق
css/style.css              التنسيق (RTL، متجاوب، طباعة)
js/app.js                  منطق التطبيق (بدون أطر عمل)
js/vendor/xlsx.mini.min.js مكتبة SheetJS لقراءة/كتابة Excel (Apache-2.0)
sw.js                      Service Worker للعمل بدون إنترنت
manifest.webmanifest       ملف تعريف التطبيق (PWA)
icons/                     أيقونات التطبيق
```

### التطوير محلياً

أي خادم ملفات ثابتة يكفي، مثلاً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

عند تعديل الملفات ارفع رقم الإصدار في `sw.js` (`CACHE`) حتى تُحدَّث النسخة المخزنة لدى المستخدمين.
